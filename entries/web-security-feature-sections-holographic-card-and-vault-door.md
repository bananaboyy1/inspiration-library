# Security Sections: Holographic Card and Vault Door

![](../images/web-security-feature-sections-holographic-card-and-vault-door.jpg)

**Discipline:** web · **Design type:** Landing page sections
**Tags:** security, monochrome, holographic, vault, black, pills, photography

## What it is
A collage of three dark and light panels for a bank's security messaging: a hand holding a holographic credit card on grey, a black panel 'Enterprise Grade Security for Everyday Banking' with pill feature tags, and a black and white photograph of an open bank vault door with 'Bank-Level Protection' and pills.

## What it means
A vault photo is an instant metaphor for security, and a tiny rainbow sheen on the card is the only colour.

## Techniques
- Black and white vault photo as a metaphor
- Iridescent card on plain grey
- Pill tags summarising features
- Dimmed words in the headline
- Emoji inserted in a headline

## Best for
- Security sections on fintech sites
- Metaphor-led imagery
- Monochrome feature panels

## Vocabulary
- **Metaphor imagery** — A picture that stands for an idea, like a vault for security.
- **Feature pills** — Rounded tags listing key features.
- **Holographic sheen** — A rainbow-like reflective gradient on a surface.

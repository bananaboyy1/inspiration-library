# Liquid-glass quote card with green accent word

![](../images/web-liquid-glass-quote-card-green-accent.avif)

**Discipline:** web · **Design type:** UI components · **Design style:** Glassmorphism
**Tags:** glassmorphism, quote card, liquid glass, dark mode, green accent, grid

## What it is
A second variant of the jagged glass-panel quote card, this time with a green highlighted keyword and glass hexagonal prop shapes at its corners.

## What it means
Using one accent color inside otherwise white text draws the eye straight to the concept word, turning a quote into a one-glance takeaway.

## Techniques
- highlight a single keyword in an accent color instead of styling the whole quote
- vary the glass corner props (spheres, prisms) across a template set to keep a series feeling designed, not copy-pasted
- keep the background grid identical across variants to build a recognizable template family

## Best for
- quote-of-the-day social series
- dark-mode design system UI kits
- brand thought-leadership posts

## Vocabulary
- **accent color** — a single distinct color used sparingly to draw attention within an otherwise neutral palette

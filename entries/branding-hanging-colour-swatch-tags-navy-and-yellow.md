# Palette as hanging tabs with vertical hex codes in navy, indigo, yellow and white

![](../images/branding-hanging-colour-swatch-tags-navy-and-yellow.jpg)

**Discipline:** branding ·  · **Design style:** Geometric & Bauhaus
**Tags:** colour-palette, navy, indigo, yellow, dashed-lines, vertical-type, stepped-blocks

## What it is
A pale lavender page with four stepped colour blocks in descending height, each with rounded top corners and its hex code set vertically. Dashed curved lines run from the top down to a dot on each block.

## What it means
Tidy and playful; the stepped shapes read like a bar chart and the lines like strings.

## Techniques
- Stagger swatches in stepped heights like a bar chart.
- Connect each swatch to a dot via a dashed curved line.
- Rotate hex codes vertically inside the swatch.
- Fade the connector line colour to match each swatch.

## Best for
- Brand guideline palettes
- Design system documentation
- Fresh, friendly identities

## Vocabulary
- **Stepped swatches** — Colour blocks arranged at descending heights.
- **Dashed connector** — A dotted line linking elements.
- **Vertical label** — Text rotated to run up or down.
- **Hex code** — A six-digit web colour value.

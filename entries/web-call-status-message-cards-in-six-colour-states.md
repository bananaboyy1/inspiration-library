# Call status chat cards in six states: purple, grey, red, pink, green and mint

![](../images/web-call-status-message-cards-in-six-colour-states.avif)

**Discipline:** web · **Design type:** UI components · **Design style:** Minimalist
**Tags:** ui-components, chat, call, status, cards, states

## What it is
A grid of rounded chat-bubble cards for voice and video calls, arranged by state (completed sent/received, missed sent/received, outgoing sent/received), each with an icon circle, title, timestamp and a divided action row (Call again, Call back, Decline/Accept), in solid and tinted variants.

## What it means
Systematic and clear; colour and fill level encode status and direction at a glance.

## Techniques
- Encode status with hue and direction with solid versus tinted fill.
- Keep one card anatomy across every state.
- Separate actions with a hairline row.
- Label every variant for a spec sheet.

## Best for
- Messaging app design systems
- State documentation
- Component libraries

## Vocabulary
- **Component state** — A visual variant for a condition like missed or completed.
- **Tinted variant** — A light, low-saturation version of a colour.

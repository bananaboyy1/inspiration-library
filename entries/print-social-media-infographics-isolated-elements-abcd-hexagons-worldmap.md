# 'Media Infographics — Isolated infographics elements' kit with ABCD hexagon labels and a world map diagram

![](../images/print-social-media-infographics-isolated-elements-abcd-hexagons-worldmap.avif)

**Discipline:** print-social · **Design type:** Product infographic set · **Design style:** Corporate & Clean-Tech
**Tags:** infographic, media, red-teal, hexagon-labels, world-map, kit

## What it is
A teal infographic kit with a red-and-navy ribbon header, a hexagon cluster labelling categories A-E, a layered donut chart with percentages, small labelled ribbon tags (Camera, News, Letters, Internet) each with an icon, and a teal world map with location pins and connecting dotted lines under an 'Infographic Map' heading.

## What it means
Modular and reusable; presenting infographic pieces as an 'isolated elements' kit shows the components can be mixed into new layouts.

## Techniques
- Label categories with a hexagon cluster for quick reference.
- Package chart types and icons as a reusable element kit.
- Use a world map with connecting lines to show global reach.

## Best for
- Infographic component libraries
- Media and communications reports
- Global reach visualisations

## Vocabulary
- **Element kit** — A set of reusable infographic pieces meant to be combined.
- **Location pin map** — A world map marked with pins and connecting lines.

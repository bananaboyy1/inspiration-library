# User flow map with pill nodes branching from an onboarding phone

![](../images/app-user-flow-diagram-with-pill-nodes.jpg)

**Discipline:** app · **Design type:** UX documentation
**Tags:** user-flow, diagram, sitemap, grey, pill-nodes, fintech, documentation

## What it is
A light grey slide titled 'User Flow'. A large charcoal card holds an onboarding phone; thin connector lines branch to dark pills (Sign Up, Dashboard, Manage Cards, Analytics...) and lighter outlined pills for sub-steps that fade off the right edge.

## What it means
Clear and elegant; solid vs outlined nodes show primary vs secondary steps and the fading edge implies a larger system.

## Techniques
- Use filled pills for main destinations and outlined pills for sub-actions.
- Draw connectors as soft rounded elbow lines.
- Fade the far nodes to imply continuation off the page.
- Place a real screen in a dark container as the start of the flow.

## Best for
- UX case-study process slides
- Product documentation
- Explaining information architecture

## Vocabulary
- **User flow** — A diagram of paths a user takes through a product.
- **Node pill** — A rounded label representing a screen or step.
- **Elbow connector** — A line with right-angle rounded bends.
- **Fade-off edge** — Elements that fade at the frame to imply more.

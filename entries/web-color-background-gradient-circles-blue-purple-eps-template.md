# 'Color Background' template with overlapping blue-purple gradient circles and thin diagonal line strips

![](../images/web-color-background-gradient-circles-blue-purple-eps-template.avif)

**Discipline:** web · **Design type:** Background pattern · **Design style:** Gradient & Aurora
**Tags:** gradient, circles, blue-purple, background-template, minimal

## What it is
A vivid blue-to-purple gradient background with several large overlapping soft-edged circles, thin diagonal cyan line strips, a white outlined text box labelled 'Color background EPS 10' with small geometric shape icons (square, circle, triangle, X) at its corners.

## What it means
Versatile and vivid; large soft gradient circles give any content box on top instant visual richness.

## Techniques
- Overlap several large soft-edged gradient circles for depth.
- Add thin diagonal line strips as subtle texture.
- Frame a content box with small corner shape icons.

## Best for
- Poster and card backgrounds
- Landing page hero backgrounds
- Gradient template libraries

## Vocabulary
- **Soft-edged circle** — A circle with a blurred or feathered boundary.
- **Corner shape icon** — A small geometric mark used to decorate a frame's corner.

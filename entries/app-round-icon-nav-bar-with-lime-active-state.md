# Row of four round nav buttons with the settings one filled lime

![](../images/app-round-icon-nav-bar-with-lime-active-state.png)

**Discipline:** app ·  · **Design style:** Minimalist
**Tags:** components, navigation, circles, lime, grey, icons, white, minimal

## What it is
A wide white strip with four circular buttons in light grey with black icons (home, car, clock, settings), the last in lime, above a faint grey glow.

## What it means
Simple and tactile; a single lime circle marks the active tab.

## Techniques
- Use separate circles instead of a bar.
- Mark the active state with one lime fill.
- Keep icons solid black.
- Show the component alone on white.

## Best for
- Component libraries
- Navigation patterns
- Neon-accent apps

## Vocabulary
- **Round nav** — Navigation made of circular buttons.
- **Active fill** — Selected state shown by a colour fill.
- **Isolated component** — A UI piece shown alone.
- **Glow backdrop** — A soft grey bloom behind.

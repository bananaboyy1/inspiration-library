# Four chat screens: conversation list, empty list, active thread and empty thread

![](../images/app-chat-list-and-thread-screens-with-empty-states.avif)

**Discipline:** app · **Design type:** Chat interface · **Design style:** Minimalist
**Tags:** chat, messaging, empty-state, purple, mobile, ui-kit

## What it is
Four phones titled 'Chat Screens — Conversation List & Messaging': a chat list with avatars, unread badges and media previews, an empty chat list with a faded placeholder and 'No Conversations Yet', a thread with purple sent and grey received bubbles, and an empty thread with only the header and composer.

## What it means
Complete and practical; pairing each screen with its empty state shows thoughtful design.

## Techniques
- Design the empty state next to the full state.
- Use faded placeholder rows as an empty illustration.
- Keep a bottom tab bar consistent across screens.
- Label each screen above the frame.

## Best for
- Messaging apps
- UI kits
- Design handoff

## Vocabulary
- **Empty state** — What a screen shows when there is no content.
- **Unread badge** — A small count bubble for new messages.

# Grid System Columns and Margins Slide

![](../images/branding-grid-system-columns-and-margins-spec-slide.jpg)

**Discipline:** branding · **Design type:** Logo guidelines
**Tags:** grid, columns, spec, desktop, mobile, pink-glow, pills

## What it is
A grey slide titled Grid System with a numbered heading and two frames, desktop (12 columns) and mobile (6 columns), drawn as white columns with soft pink glow, labelled by pills for margins, gutters, columns and widths.

## What it means
Turning a grid into pretty glass columns makes a dry spec clear and inviting.

## Techniques
- Columns drawn as soft white bars
- Floating pills labelling each measurement
- Double-arrow icons showing spacing
- Black pills for total widths
- Pink glow behind the columns

## Best for
- Design-system grid documentation
- Responsive layout specs
- Brand guideline pages

## Vocabulary
- **Gutter** — The space between columns.
- **Margin** — The outer space between the grid and the edge.
- **Column grid** — A layout divided into equal vertical columns.

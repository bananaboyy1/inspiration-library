# Teal social network infographic with world map and stat blocks

![](../images/print-social-infographic-teal-network-world-map.avif)

**Discipline:** print-social · **Design type:** Product infographic set · **Design style:** Corporate & Clean-Tech
**Tags:** infographic, teal, world map, network, stats, corporate

## What it is
A dense teal-and-navy infographic combining a dotted world map with connection lines, colored percentage stat blocks, device icon rows, and a radar/diamond chart.

## What it means
A world map with connecting lines visually literalizes 'network' and 'global reach,' anchoring an otherwise abstract set of statistics in a spatial metaphor.

## Techniques
- use a dotted world map with arcing connector lines to represent global/network scale
- color-code stat blocks by section so a dense layout stays navigable
- mix a radar/diamond chart alongside bar charts to avoid visual monotony in a stats-heavy piece

## Best for
- social media/tech industry reports
- corporate global-reach marketing
- dense multi-metric infographics

## Vocabulary
- **radar chart** — a chart displaying multivariate data as points plotted on axes radiating from a center, connected into a polygon

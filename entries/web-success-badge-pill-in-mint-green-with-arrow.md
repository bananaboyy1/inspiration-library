# Mint green pill badge 'Success | New feature added ↗' with a lighter inner tag

![](../images/web-success-badge-pill-in-mint-green-with-arrow.webp)

**Discipline:** web · **Design type:** UI components
**Tags:** component, badge, pill, green, success, arrow, soft, ui-kit

## What it is
A mint capsule with a light green border, an inner pale 'Success' tag, the text 'New feature added' and a diagonal arrow in dark green.

## What it means
Positive and calm; a green tonal pill signals success without shouting.

## Techniques
- Use tonal green for success.
- Nest a lighter tag.
- Add a link arrow.
- Keep text dark green.

## Best for
- Success and release badges
- Status notification components
- Tonal system colours

## Vocabulary
- **Success state** — A status colour showing a positive outcome.
- **Tonal pill** — A capsule using shades of one hue.
- **Release note badge** — A small pill announcing a new feature.
- **Inner highlight** — A lighter area inside a pill.

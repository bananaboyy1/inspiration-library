# Grid System Columns over a Phone

![](../images/web-grid-system-with-column-overlay-on-phone-and-italic-serif-headline.jpg)

**Discipline:** web ·  · **Design style:** Editorial
**Tags:** grid-system, columns, fintech, serif-italic, overlay, spec, navy

## What it is
A pale page with a Grid System pill and a headline mixing light sans and bold italic serif, and a tall phone with translucent grey column bars over the screen, dimensions in italic serif above and below.

## What it means
Overlaying columns on a real screen makes the grid tangible, and italic serif measurements feel refined.

## Techniques
- Translucent column bars over a real screen
- Measurements in italic serif
- Blue-grey gradient fading up from the phone base
- Centred layout on a white page
- Mixed-weight headline

## Best for
- Grid and layout documentation
- Fintech design systems
- Explaining responsive columns

## Vocabulary
- **Column overlay** — Semi-transparent bars showing layout columns over a design.
- **Margin and gutter** — Outer space and space between columns.
- **Italic spec** — Measurements set in italic type.

# Dark rounded card inviting to 'advanced AI Voice Mode' with two blue icon-tile features, a disclaimer and a big blue Start chatting pill

![](../images/web-dark-voice-mode-invitation-card-with-blue-icon-tiles-and-pill-button.webp)

**Discipline:** web · **Design type:** UI components
**Tags:** component, modal, dark, blue, icon-tiles, ai, invitation, pill-button

## What it is
A charcoal rounded card on black with a centred bold white title, two rows each with a bright blue rounded-square icon (chat bubble, smile) and a bold feature name with a grey description, a small centred disclaimer with an underlined Learn more link, a full-width blue Start chatting pill and a plain white 'Maybe later'.

## What it means
Confident and friendly; one bright blue action on charcoal guides the choice.

## Techniques
- List features with bright icon tiles.
- Use a full-width blue pill for the primary action.
- Give the secondary action as plain text.
- Keep a small disclaimer.

## Best for
- Feature invitation modals
- AI product onboarding
- Dark cards with a single accent

## Vocabulary
- **Icon tile** — A rounded square holding an icon.
- **Primary pill** — A full-width fully rounded button.
- **Text secondary** — A low-emphasis action styled as plain text.
- **Disclaimer line** — Small grey text stating limits.

# Lime-green event poster with sticker accents and smiley icon

![](../images/print-social-poster-lime-black-event-sticker-accents.avif)

**Discipline:** print-social · **Design type:** Event poster · **Design style:** Playful & Illustrated
**Tags:** poster, event, lime green, sticker, smiley, vibrant

## What it is
A companion lime-green poster from the same agency system, announcing a 'Creative Talkshow' event with a black card, scalloped notch, orange/purple sticker badges, and a simple smiley-face icon.

## What it means
Reusing the same lime/black/sticker system for an event announcement (rather than a service list) shows how the visual language scales from general branding to a specific promo.

## Techniques
- reuse an established sticker-badge and scalloped-card system for a new specific message (event promo)
- add a simple smiley icon as a friendly focal accent within an otherwise typographic layout
- balance event logistics (date, time, RSVP) in evenly weighted sticker badges for quick scanning

## Best for
- creative agency event promotion
- youth-brand talk/workshop marketing
- playful vibrant poster template packs

## Vocabulary
- **brand system reuse** — applying an established visual language (shapes, colors, badges) consistently across different specific pieces of content

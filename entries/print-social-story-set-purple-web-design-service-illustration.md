# Purple/cream web design service story set with flat illustrations

![](../images/print-social-story-set-purple-web-design-service-illustration.avif)

**Discipline:** print-social · **Design type:** Story set · **Design style:** Playful & Illustrated
**Tags:** instagram story, web design, purple cream, flat illustration, service ad

## What it is
Four vertical story templates for a web design service, alternating cream and purple backgrounds, each pairing a flat illustration (browser mockup, toolbox, design tools, developer at desk) with a short service headline.

## What it means
Alternating background colors between adjacent stories creates visual rhythm across a highlight reel while a consistent illustration style keeps every story recognizably part of one campaign.

## Techniques
- alternate two background colors across a multi-story set for scan-friendly rhythm
- illustrate literal service metaphors (toolbox, code brackets) to make an abstract offering concrete
- leave generous white/negative space around each illustration so the flat art doesn't feel cramped

## Best for
- web design agency story ads
- freelancer/creative service marketing
- illustrated story template packs

## Vocabulary
- **service metaphor illustration** — a literal object (toolbox, gear) used to represent an abstract professional service

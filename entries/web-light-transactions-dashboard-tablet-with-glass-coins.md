# Light Transactions Dashboard on Tablet with Glass Coins

**Discipline:** web ·  · **Design style:** Corporate & Clean-Tech
**Tags:** dashboard, tablet, transactions, gradient-cards, table, status-pills, coins

## What it is
A cropped cover with a dark hand holding a tablet showing a light transactions dashboard with a sidebar, three colourful gradient summary cards, filters and a table with green, red and orange status pills, while translucent glass coins float above and a logo sits top left.

## What it means
Colourful mesh cards lift a data table, and glass coins add a playful money metaphor to a business tool.

## Techniques
- Mesh gradient summary cards above a plain table
- Status pills in three semantic colours
- Glass coin objects behind the tablet
- Hand silhouette holding the device
- Tight crop showing the UI at an angle

## Best for
- Fintech admin dashboards
- Finance tables with summary cards
- Device crops with a 3D accent

## Vocabulary
- **Status pill** — A coloured rounded label showing a state like completed or cancelled.
- **Mesh card** — A card filled with a multi-colour gradient blend.
- **Data table** — A grid of rows and columns for records.

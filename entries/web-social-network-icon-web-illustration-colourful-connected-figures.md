# Social media integration illustration: colourful platform icons connected in a web above small standing figures

![](../images/web-social-network-icon-web-illustration-colourful-connected-figures.jpg)

**Discipline:** web · **Design type:** Feature illustration · **Design style:** Playful & Illustrated
**Tags:** social-media, network, icons, colourful, illustration, marketing

## What it is
A vector illustration on a light background with colourful circular platform and function icons (phone, email, video, Facebook, chat, megaphone) connected by thin blue lines and dot nodes in a web pattern, with small silhouetted and flat-coloured human figures standing beneath as if part of the network.

## What it means
Comprehensive and reassuring; a fully connected network visualises 'integrated marketing' as one single, orderly system.

## Techniques
- Connect many small icons with thin lines into one network shape.
- Mix flat colour and silhouette figures for depth without extra detail.
- Use consistent circular containers for every icon regardless of type.

## Best for
- Marketing strategy illustrations
- SEO/SEM concept graphics
- Integrated campaign visuals

## Vocabulary
- **Network diagram** — Nodes connected by lines to show relationships or systems.
- **Icon container** — A consistent shape (like a circle) holding each icon.

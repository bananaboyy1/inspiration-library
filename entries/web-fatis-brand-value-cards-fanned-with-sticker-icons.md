# Fati's brand values: five colourful cards fanned in a wave with sticker donut icons

![](../images/web-fatis-brand-value-cards-fanned-with-sticker-icons.gif)

**Discipline:** web · **Design type:** Page section · **Design style:** Playful & Illustrated
**Tags:** values, cards, colourful, stickers, donuts, animation

## What it is
An animated section of five tilted, overlapping cards in green, hot pink, orange, periwinkle and plum ('Freshly Made', 'Made for You', 'Full of Flavor', 'Made to Share', 'Crafted with Care') each with bullet points and a white-outlined donut sticker icon at the top corner.

## What it means
Joyful and generous; each value gets its own colour, like a box of assorted donuts.

## Techniques
- Fan cards in a wave with slight rotations.
- Give each card its own saturated colour.
- Pin a sticker icon on each card's corner.

## Best for
- About and values sections
- Feature lists
- Playful brands

## Vocabulary
- **Card fan** — Overlapping cards spread in an arc.
- **Sticker icon** — An illustration with a white cut-out border.

# Tech-academy course promo grid in violet with lime highlights

![](../images/print-social-academy-course-promo-post-grid-violet.jpg)

**Discipline:** print-social ·  · **Design style:** Corporate & Clean-Tech
**Tags:** education, course, violet, lime, grid, templates, tech, bootcamp

## What it is
A black presentation board with a 3x3 grid of promo posts for a coding academy. Violet and lavender cards hold bold sans headlines, lime label bars, laptop and clock photos, and UI screenshots.

## What it means
Dynamic and modern; violet and lime feel like a tech bootcamp.

## Techniques
- Combine violet backgrounds with lime label bars.
- Mix stock photos with UI screenshots as backdrops.
- Use varying crops and layouts inside one palette.
- Present the set on black so the colours glow.

## Best for
- Bootcamp, course and academy marketing
- Template kits
- Multi-post launch campaigns

## Vocabulary
- **Label bar** — A coloured strip behind a line of text.
- **Screenshot backdrop** — Using UI images as background texture.
- **Palette lock** — Sticking to the same colours across a set.
- **Campaign grid** — An overview of all posts in a campaign.

## What it is
A very tall dark-blue case-study page: dandelion hero, client request, about box, logomark, app icon on flowers, billboard scene, UI components, branding on a hoodie and a Neue Montreal type specimen.

## What it means
One cool blue and glassy UI run through photo, product and identity, giving a complete brand world.

## Techniques
- Single blue palette through all sections
- Nature photography behind glassy UI
- Logo shown as icon, hoodie print and billboard
- Dark text tiles alternating with image tiles
- Type specimen with size and spacing specs

## Best for
- AI product identity plus UI case studies
- Long-scroll portfolio pages
- Cohesive brand storytelling

## Vocabulary
- **Logomark** — The symbol part of a logo.
- **Spec table** — A list of sizes, weights and spacing values for type.
- **Touchpoint scene** — A realistic setting showing the brand in use.

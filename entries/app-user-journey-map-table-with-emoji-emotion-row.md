# User Journey Map Table with Emotion Emoji

![](../images/app-user-journey-map-table-with-emoji-emotion-row.jpg)

**Discipline:** app ·  · **Design style:** Playful & Illustrated
**Tags:** journey-map, persona, table, lilac, red, emoji, banking

## What it is
A pale grey page titled User Journey Map with a persona card, a scenario card and a goals card, above an eight-column table of stages (Discover to Support) with rows for Activities, Pain Points in red, Touch points and an Emotional row of emoji faces with two-word feelings, the Grow column highlighted in lilac.

## What it means
Emoji make emotion readable at a glance, and pale colour-coded rows keep a dense table calm.

## Techniques
- Row labels coloured by type (red for pain)
- Emoji row showing emotion per stage
- Lilac highlight on one column
- Persona, scenario and goals cards across the top
- Uniform rounded cells

## Best for
- Journey map slides
- Banking UX research
- Dense tables with colour coding

## Vocabulary
- **Journey stage** — A phase in a user's experience such as Discover or Support.
- **Pain point** — A frustration a user experiences at a stage.
- **Touchpoint** — A place where the user interacts with the product.

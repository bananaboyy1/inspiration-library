# Navy User Flow Tree beside Phone

![](../images/app-navy-user-flow-tree-with-phone-and-italic-serif-headline.jpg)

**Discipline:** app ·  · **Design style:** Editorial
**Tags:** user-flow, tree, navy, pills, serif-italic, white, fintech

## What it is
A white slide with a User Flow pill, a headline mixing light sans and bold italic serif, a fintech phone at left and a rounded-pill tree at right with navy nodes for Sign Up, Navigation, Discover and Event and pale nodes for sub-screens.

## What it means
Navy filled nodes mark main screens while pale ones recede, so the structure reads at once.

## Techniques
- Filled navy nodes for primary screens
- Pale outlined nodes for secondary screens
- Soft shadowed pills with elbow connectors
- Phone as a visual anchor at left
- Italic serif in the headline

## Best for
- User flow documentation
- Fintech case studies
- Explaining app navigation

## Vocabulary
- **Primary node** — A filled pill representing a main screen.
- **Secondary node** — A pale pill representing a sub-screen.
- **Anchor image** — A picture placed beside a diagram to ground it.

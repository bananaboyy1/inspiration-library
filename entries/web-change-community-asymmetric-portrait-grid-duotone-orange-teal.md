# 'Change, Community' asymmetric duotone portrait grid in splattered orange and teal with bold headlines

![](../images/web-change-community-asymmetric-portrait-grid-duotone-orange-teal.avif)

**Discipline:** web · **Design type:** Landing page · **Design style:** Neo-Brutalist
**Tags:** political, duotone, orange-teal, asymmetric-grid, portraits, brutalist

## What it is
A dark portrait-heavy layout with paint-splatter textures, five duotone (orange/teal) portraits in an asymmetric offset grid, numbered corner badges, headlines ('Achange, Community,', 'Find Out Acre', 'Take Action Action.') and a bold CTA button at the bottom.

## What it means
Urgent and raw; splattered duotone portraits in an uneven grid feel activist and unpolished on purpose.

## Techniques
- Duotone portraits in two clashing bold colours.
- Break the grid into deliberately uneven, offset blocks.
- Add paint-splatter texture for a grassroots, non-corporate feel.

## Best for
- Political and activist campaigns
- Community organising sites
- Bold editorial layouts

## Vocabulary
- **Duotone** — An image rendered using only two colours.
- **Asymmetric grid** — A layout grid with deliberately uneven block sizes.

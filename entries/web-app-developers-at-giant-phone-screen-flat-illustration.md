# Two flat-illustrated developers working around a giant phone screen showing app UI elements and icons

![](../images/web-app-developers-at-giant-phone-screen-flat-illustration.jpg)

**Discipline:** web · **Design type:** Feature illustration · **Design style:** Gradient & Aurora
**Tags:** app-development, flat-illustration, phone, ui-icons, gradient, transparent

## What it is
A flat vector illustration of a man and woman standing on either side of a giant smartphone displaying colourful UI cards, checkmarks, a play button and a chart, surrounded by floating icon panels (envelope, cloud, chat) and abstract leaf shapes, on a transparent background.

## What it means
Collaborative and approachable; showing two people physically interacting with an oversized phone makes app development feel like teamwork, not solitary code.

## Techniques
- Scale a device to giant size so figures can interact with it directly.
- Float smaller UI icon panels around the main scene for context.
- Render on a transparent background for flexible reuse.

## Best for
- App development marketing
- SaaS feature illustrations
- Team collaboration graphics

# Magenta/yellow travel app onboarding with phone mockup

![](../images/app-onboarding-travel-app-magenta-yellow-illustration.avif)

**Discipline:** app · **Design type:** Onboarding screens · **Design style:** Playful & Illustrated
**Tags:** onboarding, travel app, magenta yellow, phone mockup, illustration

## What it is
A phone mockup showing a travel-itinerary UI screen beside three flat-illustrated onboarding cards (travel assistant, beach & cocktail, currency exchange) in a magenta/yellow palette with pill-shaped buttons.

## What it means
Pairing one real functional UI screen with several illustrated pitch cards lets the design sell both 'what the app does' (illustration) and 'what it looks like' (real screen) in one image.

## Techniques
- show one functioning UI screen alongside several illustrated benefit cards side by side
- alternate card background colors (blue/yellow) across an onboarding set to signal distinct steps
- use pill-shaped buttons consistently to unify CTAs across illustrated and real UI screens

## Best for
- travel app onboarding and marketing
- consumer app store screenshot sets
- illustrated onboarding template packs

## Vocabulary
- **pitch card** — a single onboarding screen designed to sell one specific feature or benefit before the user reaches the main app

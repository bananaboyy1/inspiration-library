# Liquid-glass quote card with crystalline cube props

![](../images/web-liquid-glass-quote-card-cube-accent.avif)

**Discipline:** web · **Design type:** UI components · **Design style:** Glassmorphism
**Tags:** glassmorphism, quote card, liquid glass, dark mode, 3d glass, grid

## What it is
A third variant of the glass quote card series, using faceted crystal cube shapes instead of spheres at the panel corners.

## What it means
Swapping only the prop geometry across a template family shows how a design system can stay recognizable while still varying enough to avoid repetition fatigue.

## Techniques
- build a template family by holding background and typography constant while rotating one decorative element
- use faceted, multi-plane props to catch varied light angles and add realism

## Best for
- quote-of-the-day social series
- dark-mode design system UI kits

## Vocabulary
- **faceted** — having multiple flat plane surfaces, as cut on a gemstone, used to catch and vary light reflection

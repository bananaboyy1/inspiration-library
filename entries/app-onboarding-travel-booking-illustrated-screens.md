# Illustrated travel booking app onboarding set

![](../images/app-onboarding-travel-booking-illustrated-screens.avif)

**Discipline:** app · **Design type:** Onboarding screens · **Design style:** Playful & Illustrated
**Tags:** onboarding, travel app, flat illustration, booking, blue orange

## What it is
Three vertical app screen mockups for a travel booking flow (plan trip, book a taxi, in-flight), each combining flat illustrated scenes with real UI elements like search fields and carousel dots.

## What it means
Blending illustrated scenes with functional-looking UI chrome (search bars, buttons, dot indicators) makes onboarding screens feel like real, working app previews rather than abstract marketing art.

## Techniques
- combine flat illustration panels with genuine UI components (search fields, nav bars) in the same screen
- use consistent carousel dot indicators to signal progress through an onboarding sequence
- color-code each onboarding step's illustration differently while keeping UI chrome neutral

## Best for
- travel/booking app onboarding
- illustrated app walkthrough templates
- consumer travel product marketing

## Vocabulary
- **carousel dots** — small dot indicators showing a user's position within a sequence of swipeable screens

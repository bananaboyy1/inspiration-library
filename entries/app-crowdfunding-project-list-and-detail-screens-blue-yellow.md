# Crowdfunding app screens: a project list with progress bars and a detail screen with an investor bar

![](../images/app-crowdfunding-project-list-and-detail-screens-blue-yellow.avif)

**Discipline:** app · **Design type:** UI components · **Design style:** Corporate & Clean-Tech
**Tags:** crowdfunding, fintech, blue, yellow, progress-bar, app-ui

## What it is
Two phone screens on a blue geometric background: 'Your projects' listing yellow-tagged project cards with photos and progress bars showing amount raised versus goal, and a detail screen for 'Powerful smart battery lamp' with a description, an investor progress bar (700 investors) and a black 'Select' button.

## What it means
Trustworthy and motivating; progress bars on every card make funding momentum visible at every level of the app.

## Techniques
- Show a funding progress bar on both list and detail views.
- Tag each project card in one consistent accent colour.
- Pair a description with a separate social-proof bar (investor count).

## Best for
- Crowdfunding platforms
- Fintech app UI
- Progress-driven product design

## Vocabulary
- **Progress bar** — A bar showing how far a goal has been reached.
- **Social proof** — Evidence like investor counts that build user trust.

# Grid-based texture configurator site on laptop with ice

![](../images/web-modular-grid-configurator-on-laptop-ice.png)

**Discipline:** web · **Design type:** Interactive site concept
**Tags:** grid, monochrome, configurator, laptop-mockup, ice, minimal, monospace, interactive

## What it is
A laptop showing a white site divided by visible grid lines with a nav on top, tiles showing black texture swatches, small pill buttons and monospace text; next to it is a chunky black wordmark and glacial ice in the background.

## What it means
Precise, cool and experimental; the grid and ice suggest clarity and design engineering.

## Techniques
- Expose the layout grid as visible hairlines that become the main graphic.
- Fill cells with tactile texture swatches for a tool-like interactivity.
- Use monospace and tiny pill buttons for a technical voice.
- Stage the mockup in a cold natural environment that matches the concept.

## Best for
- Design tools and material or pattern libraries
- Experimental studio sites
- Product configurators

## Vocabulary
- **Visible grid** — Layout lines shown as part of the design.
- **Configurator** — An interface for combining options to build something.
- **Monospace type** — Type where every character has equal width.
- **Swatch** — A small sample of colour or texture.

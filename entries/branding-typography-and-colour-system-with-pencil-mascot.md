# Typography and colour page with a pencil mascot and weight slider

![](../images/branding-typography-and-colour-system-with-pencil-mascot.jpg)

**Discipline:** branding · **Design type:** Typography and colour guide
**Tags:** typography, colour-palette, mascot, navy, italic-serif, weight-slider, brand-guidelines

## What it is
A white page with a headline mixing regular sans and bold italic serif, a cartoon pencil character leaning on giant 'Helvetica Neue' type, a horizontal weight slider (Light, Regular, Medium, Bold), and a circular colour chart showing five blues with percentages around a script 'p' logo.

## What it means
Friendly, structured and clear; the mascot humanises the guidelines and the ring makes proportions instantly visible.

## Techniques
- Show colour proportions as segments of a ring around the logo.
- Demonstrate type weights with a draggable-style slider.
- Add a cartoon mascot to lighten a technical page.
- Contrast light sans with italic serif in the headline.

## Best for
- Brand guideline pages
- Design-system typography and colour docs
- Friendly fintech identities

## Vocabulary
- **Colour ring** — A circular chart showing each colour's share.
- **Weight slider** — A control showing the range of font weights.
- **Mascot** — A character used to represent a brand.
- **Palette proportion** — The percentage of each colour used in a brand.
